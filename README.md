# My Cookbook

A web app built with PHP and MySQL for UXID241 at Drexel University. By the end of the term it will let users browse recipes, search by ingredient or category, and view full recipe pages with steps, images, and tools needed.

## How to run locally

1. Make sure MAMP is installed and running
2. Place this project folder inside your MAMP `htdocs` directory
3. Open phpMyAdmin (http://localhost:8888/phpMyAdmin) and create a database called `cookbook`
4. Import `schema.sql` into that database to create the tables and seed data
5. Copy `config.example.php` to `config.php` and fill in your database credentials
6. Visit http://localhost:8888/uxid241-jlg493/ in your browser
